about=Versi 2.8.4 memperbaiki umpan balik penyimpanan Catatan Titik Bangunan, menjelaskan status edit buffer jika layer sudah dalam mode edit, dan menyiapkan update dari ZIP GitHub Release secara bertahap dengan validasi struktur serta cadangan sebelum diterapkan. Versi 2.8.3 memperbaiki Catatan Titik Bangunan dengan toleransi klik dan pembuatan kolom catatan otomatis pada layer yang dapat diedit; kontrol jendela memakai warna netral dan menu Cek Update GitHub memeriksa rilis terbaru. Fitur sebelumnya tetap tersedia. Versi 2.8.2 menyertakan layer titik KdKec_3210200.gpkg sebagai acuan bawaan Titik Pusat BPS. Layer acuan otomatis dimuat bila belum ada; dropdown tetap bisa dipilih manual. Memindahkan titik bangunan secara manual atau melalui kandidat raster. Fitur flag=1 dapat di-zoom otomatis; setelah target diedit, flag pada layer hasil menjadi 0. Peta sumber difilter sementara sehingga hanya titik pada kode desa + SLS aktif yang terlihat. Menyimpan output AutoSnap permanen ke GeoPackage. Antarmuka diperbarui dengan tata letak modern, menu utama langsung, panel metrik, tab dan tabel yang lebih jelas. Raster georeference dapat dipilih secara manual melalui dropdown Raster SLS atau tombol Choose; raster terpilih dicentang dan raster georeference lain dilepas centangnya; pilihan otomatis dicocokkan berdasarkan nama SLS dan akhiran _WSS diabaikan dan visibilitas awal dipulihkan saat dialog ditutup. Menyediakan menu Audit Laporan Titik untuk memilih layer acuan dan group/layer pekerjaan. Sumber tidak ditimpa. Load Style memakai hijau seragam; setiap layer output memakai satu warna berbeda per layer, bukan per FID. Label no_bang putih tebal berbuffer hitam.
